# 소리틀 SORITOOL V1.0

**SORITOOL** is a Windows voice-conversion and audio-editing application developed and published by **JEPARI**.

소리틀은 레퍼런스 음성과 성별·연령·음색 조절 기능을 제공하는 Windows용 음성 변환·편집 프로그램입니다.

## 공개 진행 상황 / Source publication status

**소스 공개 준비 중 / Source publication in progress.**

JEPARI has approved publication of its original SORITOOL source code under GNU GPL version 3. The corresponding source and related build materials are under review before release.
